- The conservation outlet no longer lets flow back into the domain (83914dbd). Once per time step it checks whether its uniform flux correction would leave any outlet face with inflow; if so, faces whose copied flux is reversed get zero flux and the rest are scaled to carry the same total. The choice is held for the whole step so Newton-Krylov residuals stay smooth. Runs with no reversed face are unchanged to the bit; steps that clip log a warning with the counts and the scale factor.
